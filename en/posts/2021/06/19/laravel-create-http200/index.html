【Laravel】Returning HTTP 200 After Creating a Model

posted: 2021-06-19

Laravel

When you create and return a model in Laravel, the HTTP status is automatically set to 201.
If you have a reason to return it as HTTP 200, you can set the wasRecentlyCreated property of the model to false.

public function store()
{
    $hoge = HogeModel::create();
    $hoge->wasRecentlyCreated = false; // It is true upon creation
    return $hoge;
}
